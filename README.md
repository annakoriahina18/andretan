# ANDRE TAN — Instagram Design System

Дизайн-система Instagram для бренду ANDRE TAN: токени, компоненти та шаблони (пости, каруселі, Stories, Highlights, реклама, сітка профілю).

- Онлайн: див. GitHub Pages цього репозиторію (`/design-system/`)
- Локально: `powershell -ExecutionPolicy Bypass -File design-system/serve.ps1` → http://localhost:5500

Кольори та шрифти — у `design-system/tokens.css`.
